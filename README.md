# Queens of Change Foundation Website

I designed and built this single-page website from scratch to showcase the incredible work the Queens of Change Foundation does for women's empowerment, menstrual health, and vocational skilling. My main goal was to build a clean, respectful, and highly professional website that stands out.

---

## 🎯 What I Focused On

I wanted to make the website feel interactive and premium by adding these features:

* **Official Branding**: I used the official Queens of Change logo in the navbar and footer, and designed the main color theme using the logo's deep wine crimson and soft gold colors.
* **Eye-Friendly Dark Mode**: I added a working dark mode toggle. To make it soft on the eyes, I toned down the pink accents and kept text highly readable. It also saves your theme preference so it stays even if you refresh the page!
* **Smooth Animations**: Added simple fade-in animations as you scroll to make the transitions feel smooth.
* **Animated Counter Stats**: In the impact section, the numbers count up dynamically as soon as you scroll them into view.
* **Scroll Tracker (Scroll-Spy)**: The navigation menu automatically highlights which section you are reading as you scroll down.
* **Fully Responsive**: The layout looks great on desktops, tablets, and phones.

---

## 📂 Project Files

* `index.html` - The main structure of the page (with clean, commented sections).
* `style.css` - Custom styling, layout rules, and theme transition code.
* `script.js` - JavaScript for scroll triggers, dark mode toggle, and count-up stats.
* `assets/` - Folder for logos, background banners, and illustrations.

---

## 🚀 How to Run the Project

You don't need to install anything to run this project:

1. Clone or download this repository.
2. Open the folder.
3. Double-click `index.html` to open it in your browser!

*(Note: If you want to run it on a local server, you can open your terminal in this folder and run `python -m http.server 8080` or use the VS Code Live Server extension).*
